IF SOMETHING FAILS:

  Status: 422
  RESPONSE BODY:
    {
      "error": {
        "code": "VALIDATION_FAILED",
        "details": {
          "email": "must be a valid email address"
        }
      }
    }

  → The error message tells you exactly what's wrong!

================================================================================

STATUS CODES:

  200, 201, 204  = Success ✓
  400, 401, 422  = Client error (check request format or auth)
  500, 503       = Server error (API crashed)

  Q: I don't see any API calls

  A: Save to file: DEBUG=1 uvicorn app.main:app --reload 2>&1 | tee /tmp/rory.log

  Q: I want to see only errors
  A: grep "Status: [4-5]" your_log_file.txt
